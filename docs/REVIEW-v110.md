## 2. 逐项核查结论

| 检查项 | 结论 |
|---|---|
| **金额单位（元 vs 分）** | 无问题。service / schema 层全部「元」（Decimal→float），只有 `Money` 落地转分；`MAX_AMOUNT = 1e9 元` = 1e11 分，SQLite INTEGER 容得下 |
| **可加总口径** | 无问题。`SUMMABLE` 直接复用 `enums.SUMMABLE_CATEGORIES`，不再各处手写 |
| **医疗取 max** | 无问题。同保单多条医疗取 max、跨保单再取 max，均有断言（场景 10） |
| **byMonth = 年化合计** | 无问题。月缴 `allocate_amounts` 平摊、年缴落生效月；15 个场景全部断言之 |
| **交费计划期次** | 无问题。`k = max(paid_periods, k_max+1)` 同时兼容提前缴、逾期、趸交、已缴清；提前缴 5 期时正确地不再出现在未来 1 年计划里（场景 5） |
| **月末截断** | 无问题。1/31 + 1 月 → 2/28（复用 `calc.add_months`），闰日 2/29 + 60 年 → 2060-02-29（场景 13） |
| **到期边界** | 无问题。保障结束日 = 今天 → 仍在保、`daysLeft=0` 进「即将到期」；昨天 → 过期（场景 8/9） |
| **除零 / NaN** | 无问题。年收入 0 → `filled=false`、`premiumRatio=null`、不给额度缺口；`json.dumps(allow_nan=False)` 全场景通过 |
| **前端事件重复绑定** | 无问题。监听器只绑一次（`dataset.reportBound`），刷新只换 `innerHTML` |
| **XSS / 转义** | 无问题。所有插值字段过 `escapeHtml`，数字走 `fmt*` 格式化 |
| **Word 生成** | 无问题。空列表 / None / 日期 str 化均有兜底；导出物用 `python-docx` 回读校验，表数量、关键文案、金额一致（含「新增保单后导出立刻变化」） |
| **迁移幂等** | 无问题。旧库（删掉 `policy_coverages`）重启自动补建，`policies`/`members` 行数不变，关联表回填 1 行，重复执行不重复插入 |
| **鉴权** | 无问题。三个端点都 401（含 `export.docx`）；公开接口仍只有 health / enums / auth |

## 3. 报告内容复核（口径与措辞）

| 结论 | 判定 |
|---|---|
| 「在保 5 张、退保 1 张」 | 正确，退保保单不进保额与保费，仍在汇总表标注 |
| 「给付型保额 270 万 = 重疾 50 + 身故 200 + 意外 20」 | 正确，医疗 400 万未计入 |
| 「寿险缺口 10 万 = 210 万 − 200 万」 | 正确（负债 120 万 + 5×18 万 = 210 万） |
| 「保费负担率 10.4%，在 5%–15% 区间」 | 正确（37,448 / 360,000） |
| 「配偶寿险共保，请核对本人份额」 | 正确，不再虚构缺口 |
| 「6 岁孩子重疾参考 50 万」附注「不按收入测算」 | 正确且必要 |
| 「1 张保单未录责任，结论仅供参考」 | 正确，且在封面、警示条、口径说明三处一致出现 |
| 医疗 400 万显示为「报销限额」而非保额 | 正确，页脚与章节说明都写清 |

**可以更保守但没有改的地方**（记录在案，供后续判断）：

- 意外险里的「意外医疗」按类别归到 `医疗`，会让孩子的「医疗」显示 5 万。
  这是真实存在的保障，不算错，但与百万医疗同列容易让人误解量级；
- 年金险计入矩阵「年金」列但不进给付合计，家庭总保额看起来会比保单保额之和低——
  已用「给付型保额」这个措辞和脚注区分。

## 4. 遗留风险（不阻塞发布）

1. **`calc_schedule` 对脏数据不设防**：`payment_term_type='固定年限'` 而 `payment_term_value` 为空时
   会 `TypeError`（旧库手改数据才会出现，API 层已强制校验）。属既有行为，本次未改，
   若后续要做「导入历史数据」需一并加固。
2. **`python-docx` + `lxml` 是首次引入的二进制依赖**：离线镜像的 wheel 目录需同步补齐，
   已在 `requirements.txt` 注明；镜像已实测能装上（见发布记录）。
3. **打印分页依赖 `break-before`**：Chrome / Edge / Safari 均支持，旧版 Firefox 可能不理想，
   但不影响内容完整性。
