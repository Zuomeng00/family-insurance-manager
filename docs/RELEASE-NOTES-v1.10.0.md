## v1.10.0 — 保单托管报告 + 保障责任拆解

把库里散落的保单，变成一份**能拿给人看**的《家庭保障检视报告》。

### 新功能

**保单托管报告**（顶栏「保单托管报告」）

九章、A4 打印约 11 页：

1. 保障总览 — 成员 × 保障类别矩阵（重疾 / 医疗 / 意外 / 身故全残 / 年金 + 给付合计）
2. 保障缺口分析 — 填 3 个参数（家庭年收入 / 负债 / 年生活支出）算额度缺口；结构缺口自动列出
3. 保障诊断小结 — 自动生成的结论：覆盖情况、保费负担率、身故责任能否盖住负债
4. 成员保障分析 — 逐人：有什么、缺什么、每张保单的责任明细
5. 保费分布 — 按投保人 / 按险种 / 12 个月支出节奏
6. 保单汇总 — 全字段，未计入合计的保单灰显并标注原因
7. 交费计划 — 未来 12 个月逐期待缴，含合计
8. 行动清单 — 按优先级：已过期 → 30 天内到期 → 逾期 → 结构缺口 → 额度缺口 → 补录责任
9. 测算口径与说明 — 口径、排除项、免责

**报告是现算的**：每次打开重新聚合，不建快照表。保单新增、到期、退保、补录责任后，
下次打开就是新数。`导出 Word` 与页面用的是同一次结果。

**保障责任拆解**（保单列表每行「责任」）

一张重疾险的保额不是「50 万」一个数：重疾 100%、中症 60%×2、轻症 30%×3、身故另算。
新增 `policy_coverages` 表把这堆条款拆成一条条可汇总的记录，按险种一键套模板。

### 口径（写进报告，不藏着）

- 只有「生效中 / 已缴清」**且在保障期内**的保单计入保障与保费；已退保、已失效、
  已过期（状态没改）都不计，并单独提示；
- 医疗险是报销限额，**不参与「总保额」加总**，取最大值；
- 多被保人保单的保额记主被保人，并提示「请对照条款核对本人份额」——不虚构缺口；
- 未成年人重疾按 50 万、意外按身故给付监管上限测算，不用「3 倍家庭年收入」
  （那会算出「6 岁孩子缺 90 万」）；
- 缺口参考值是**行业经验值，不是监管标准**，报告里明确标注。

### 升级说明

- **新增一张表** `policy_coverages`，首次启动自动创建；不新增列、不回填，**不需要你操作**；
- 老数据原样可用：没录责任的保单按险种与保额粗算，并在报告里提示补录；
- 镜像比上一版大约 13 MB —— Word 导出首次引入 `python-docx` + `lxml`（离线 wheel 已内置）；
- 照旧建议升级前备份整个 `data/` 文件夹。
